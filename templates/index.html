How It Works

Understanding the 4-step pipeline behind fingerprint blood group classification.

01

1. Image Upload

The user submits a fingerprint image (PNG, JPG, BMP) via the dashboard interface.

02

2. Preprocessing

The image is resized to 64x64 pixels, normalized, and converted into a numerical tensor array.

03

3. Deep Learning

The trained Convolutional Neural Network extracts feature maps from ridge patterns.

04

4. Prediction

The model outputs class probabilities for A+, A-, B+, B-, AB+, AB-, O+, and O-.

About the Project

Explore the motivation, scope, and technical background.

Problem Statement

Traditional blood grouping requires invasive serological blood sampling via finger pricks or venipuncture. This project explores whether physiological dermal patterns in fingerprints carry correlations suitable for non-invasive machine learning classification.

Objective

To construct a prototype deep neural network pipeline capable of processing fingerprint images and classifying predicted blood group labels with confidence scores.

Approach

Fingerprint scans are preprocessed into normalized 64x64 tensors and passed through a Convolutional Neural Network (CNN) model trained on annotated fingerprint datasets.

Project Limitations

Predictions depend heavily on image clarity, lighting, sensor calibration, and dataset diversity. This software is an academic exploratory project and must never replace clinical diagnostics.
